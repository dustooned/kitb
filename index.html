    Importing from Photoshop / Affinity / Illustrator

    Photoshop (.psd) imports with layers intact — each Photoshop layer becomes its own layer here. Affinity files (.afphoto/.afdesign) can't be read directly (no public file format), but Affinity can export as .psd (File → Export → Photoshop), which imports the same way. Illustrator/PDF (.ai/.pdf) comes in as one flattened image (vector shapes aren't kept editable). Plain images (PNG/JPG/WebP) always work.

    Everything autosaves in this browser. Use Export ZIP to hand in your work or move it to another computer — it includes a kit.json save file plus every card/piece/board image.
